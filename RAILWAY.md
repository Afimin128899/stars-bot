# Stars Bot на Railway 🚀

## Развёртывание на Railway

### Шаг 1: Подготовка
1. Создай аккаунт на [railway.app](https://railway.app)
2. Соедини GitHub репозиторий
3. Создай новый проект

### Шаг 2: Переменные окружения

Добавь в Railway переменные:

```
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
ADMIN_ID=123456789
```

**Как получить BOT_TOKEN:**
1. Напиши боту [@BotFather](https://t.me/botfather)
2. Отправь `/newbot`
3. Следуй инструкциям
4. Скопируй полученный токен

### Шаг 3: Запуск

Railway автоматически:
1. Установит зависимости из `requirements.txt`
2. Запустит `python main.py` (из Procfile)
3. Бот будет постоянно работать

### Шаг 4: Логи

В Railway можно смотреть логи бота в реальном времени:
- Перейди в проект → Service → Logs

## Проблемы и решения

### Бот не запускается
- Проверь `BOT_TOKEN` в переменных окружения
- Убедись, что токен правильный

### Ошибка при импорте модулей
- Убедись, что все зависимости в `requirements.txt`
- Перезагрузи сервис (Deploy → Redeploy)

### База данных не сохраняется
- Railway удаляет данные при перезагрузке
- Для постоянного хранилища используй PostgreSQL в Railway

## Добавление PostgreSQL (опционально)

1. В Railway: Add Service → PostgreSQL
2. Railway автома��ически создаст переменные окружения
3. Обнови `database.py` для подключения к PostgreSQL

## Команды бота

- `/start` - Начать
- `/profile` - Профиль
- `/tasks` - Задания
- `/withdraw` - Вывести звёзды
- `/top` - Топ пользователей

## Поддержка

Если возникли проблемы:
1. Проверь логи в Railway
2. Убедись что токен верный
3. Перезагрузи сервис
